// PEER-REVIEWED PUBLICATION · 2025

Domain-Adaptive Stressor Identification Using Fine-Tuned BERT and NER Techniques

Prem Kumar G Raga · RVITM CSE · IIT Madras Data Science

Abstract & Key Contribution

Extracting psychological and physiological stressors from informal, domain-diverse text represents a crucial bottleneck for automated clinical diagnosis. This research establishes a domain-adapted transformer architecture coupling fine-tuned BERT representations with token-level Named Entity Recognition (NER) token classification heads. Through domain-adaptive pretraining and specialized cross-entropy loss weighting, the model overcomes severe class imbalance across clinical text, outperforming traditional sequence classifiers by +14.8%.

91.4% F1-SCORE
92.1% PRECISION
90.7% RECALL
+14.8% VS BASELINES

Model Architecture Flow

Raw Medical Text → Domain WordPiece Tokenizer → 12-Layer Transformer (BERT) → Token-Level Linear Head → BIO Stressor Span Extraction
