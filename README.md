## 🌐 1-Click Deployment

### Deploy to Vercel
1. Push this repo to your GitHub (`jackelKing/PORTFOLIO`).
2. Go to [vercel.com](https://vercel.com), click **Add New Project**, and import this repository.
3. Framework Preset: **Other** (Root directory: `./`).
4. Click **Deploy**. Vercel will automatically read `vercel.json` and deploy globally in under 20 seconds.

### Deploy to Render
1. Go to [render.com](https://render.com) and click **New Static Site**.
2. Connect your GitHub repository.
3. Publish Directory: `./` (or leave empty).
4. Click **Create Static Site**.
